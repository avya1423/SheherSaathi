# SheherSaathi - India's #1 Student City Companion

> **Har Naye Shahar Mein Aapka Saathi** 🌍

SheherSaathi is a comprehensive web application designed to help students and newcomers settle into new cities. It provides verified accommodation listings, smart fare calculation, expense tracking, and essential city services all in one platform.

**Live Demo:** https://avya1423.github.io/SheherSaathi/

## 🚀 How to Use

### Finding Accommodation
1. Click on "Private Flats & PGs" in the navigation
2. Use filters to narrow down by city and budget
3. Search by location name
4. Click "View & Contact" to reach the owner
5. Visit the property and verify in person

### Calculating Fares
1. Navigate to "Fare Calculator"
2. Enter pickup location (e.g., Railway Station)
3. Enter drop location (e.g., Your Flat)
4. Click "Calculate Fare"
5. Compare bike, auto, and cab rates

### Tracking Expenses
1. Go to "Expense & Split Bill" section
2. Enter expense name (e.g., Room Rent)
3. Add amount and select split type
4. Click "Add Expense"
5. View expense ledger below
6. Reset ledger anytime

### Listing a Property
1. Click "List Property" button in navbar
2. Fill in property details
3. Select city and price
4. Add contact information
5. Click "Deploy Listing"
6. Property appears in directory

### Emergency Help
1. Click on "Emergency Helpline" in mobile menu
2. Find required helpline number
3. Call immediately for assistance
4. SheherSaathi support: +91 98765 43210

## 💾 Data Storage

All data is stored **locally in your browser**:
- No cloud servers
- No data sharing
- 100% privacy
- Full user control
- Can be cleared anytime

**To clear all data:**
1. Open browser DevTools (F12)
2. Go to Application → LocalStorage
3. Clear all SheherSaathi entries
4. Or use "Reset Ledger" button
